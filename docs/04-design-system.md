# NUVAIX Design System

## Color

Midnight Sapphire #0A1D3D
Titanium Silver #C0C6CF
Champagne Gold #D4AF37
Deep Black #030507
Off White #F5F5F2

## Visual principles

- dark luxury
- architectural geometry
- restrained gold accents
- metallic/silver typography accents
- generous whitespace
- cinematic photography
- strong grid discipline
- subtle glass/metal surfaces only when useful

## Avoid

- excessive gradients
- neon cyberpunk
- excessive glow
- giant animated text
- random glassmorphism
- overuse of 3D
- generic stock-business imagery
- crowded cards

## Typography

Use one strong modern sans family for the interface and a restrained display treatment.
Use uppercase, tracked typography selectively for section labels and premium headings.

## Spacing

Use a consistent spacing scale and generous section padding.
Use a max-width content container rather than arbitrary widths.

## Buttons

Primary: dark/sapphire surface + gold treatment.
Secondary: transparent/outlined.
Always include visible hover and focus states.

## Motion

- 150–250ms micro-interactions
- 400–800ms section reveals
- slow hero imagery movement
- no motion required for comprehension
- honor reduced-motion preferences
