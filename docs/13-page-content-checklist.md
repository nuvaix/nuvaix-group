# Page Content Checklist

Every page should answer:

1. What is this?
2. Why does it matter?
3. What does NUVAIX actually provide?
4. Who is it for?
5. Why should the visitor trust the offering?
6. What should the visitor do next?

Every page must have:

- title
- meta description
- H1
- supporting copy
- CTA
- mobile layout
- loading/error state where applicable
- accessible interactions
- SEO metadata
