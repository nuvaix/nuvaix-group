# Security

- Never commit secrets.
- Validate server-side.
- Sanitize/encode rendered user content.
- Protect form endpoints.
- Add rate limiting / anti-spam.
- Validate file type and size for uploads.
- Store uploads outside the public directory where appropriate.
- Use secure headers.
- Keep dependencies updated.
- Do not expose private founder/company information.
- Review all third-party integrations before production.
