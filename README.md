# NUVAIX GROUP Website

Premium corporate website for NUVAIX GROUP.

## First setup

1. Install Node.js LTS.
2. Open VS Code.
3. Open the terminal.
4. Create the Next.js application in this folder/repository.
5. Read `CLAUDE.md`.
6. Read the files under `docs/`.
7. Give Claude Code the phased prompts from `docs/14-claude-code-build-sequence.md`.

## Important

Do not ask Claude Code to build the entire website in one prompt.
Build and review one milestone at a time.

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- Motion for UI animation
- React Hook Form + Zod for forms
- Transactional email provider for production forms
- Optional CMS/database later
